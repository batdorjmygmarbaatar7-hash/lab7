# BUG-03: API буруу JSON биетэй POST хүсэлтэд 400-ийн оронд 200 OK буцаана

Орчин: Уншлагын жагсаалт v2.0, curl (терминал), Ubuntu Linux, 2026-10-20
Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан

## Дахин гаргах алхам
1. Терминал нээх
2. Дараах командыг ажиллуулах:
   curl -i -X POST localhost:3000/api/books -H "Content-Type: application/json" -d 'буруу оролт'
3. Хариуны эхний мөр (статус код)-ыг харах

Хүлээгдэж байсан: Спек дүрэм #8-оор (буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана) — HTTP/1.1 400 буцаах ёстой.
Бодит үр дүн: Сервер HTTP/1.1 200 OK статус болон {"result":"OK"} бие буцаав. Буруу JSON-ыг алдаа гэж үзэлгүй амжилттай хүлээж авав.
Ноцтой байдал: Major — API гэрээ зөрчсөн; буруу оролтыг чимээгүй залгих нь клиентүүдийг төөрөгдүүлж, алдаа нуугдахад хүргэнэ.
